# HireAI – Connect the Future

Welcome to the *HireAI* project – an AI-powered recruitment platform designed to simplify and optimize the hiring process using modern technologies.

## Project Overview

HireAI is built using a modern tech stack to deliver high performance and seamless user experience. The project aims to provide a streamlined solution for companies and candidates to connect through smart matching, filtering, and interaction features.

## Tech Stack

This project is built with:

- Vite – Next-generation frontend tooling.
- TypeScript – Static typing for improved reliability.
- React – Component-based UI library.
- shadcn/ui – Accessible UI components.
- Tailwind CSS – Utility-first CSS framework.

## Getting Started

To run the project locally:
1. Clone the repository
git clone <YOUR_GIT_URL>

2. Navigate into the project folder
cd <YOUR_PROJECT_NAME>

3. Install dependencies
npm install

4. Start the development server
npm run dev
```

> Make sure you have [Node.js](https://nodejs.org/) and npm installed on your machine.
